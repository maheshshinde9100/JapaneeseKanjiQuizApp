# Kanji Reading Quiz

A lightweight quiz for practicing **86 Japanese kanji** with **On’yomi** and **Kun’yomi** readings. Built with HTML, CSS, JS, and Bootstrap.

## Features
- On’yomi / Kun’yomi practice  
- Multi-select answers & instant feedback  
- Score, streak, and progress tracking  
- Responsive, animated interface  
- Skip, reset, and stats modal
